- Planner: team task boards with owners/dates/status; only relevant if the user actually uses them. Standard Graph Planner support and premium-plan limitations need current endpoint verification.
- SharePoint Lists: structured project/opportunity/risk trackers. Existing site-read scopes may support reads; writes need additional approval/scopes.

- Scoped file/site write permissions only for explicitly requested editing workflows.

No To Do or OneNote modules. These possibilities are not capability promises or reasons to request blanket permissions.
