# Fonts

Latin subsets (woff2) fetched from Google Fonts. All three families are licensed under the SIL Open Font License 1.1.

- Shippori Mincho B1 (400): titles. `shippori-mincho-b1-kanji-logo.woff2` is a 3-glyph subset (金 継 間) for the logo mark.
- Zen Kaku Gothic New (400, 500): body and labels.
- IBM Plex Mono (400): numerals, footer, captions.

Only Latin glyphs are bundled for the text families. Other scripts fall back to the system fonts in `--font` and `--font-title`.
